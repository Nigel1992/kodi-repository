Kodi Add-on Repository

Nigel's Kodi Repository

A curated collection of add-ons for Kodi. Add the source once, install the repository, and every add-on stays up to date automatically.

Download Repository (.zip) How to install

Install in 3 steps

Go to Settings → File Manager → Add Source and click <None>.

Give the source a name, e.g. Nigel Kodi.

Enter the source URL below and press OK.

https://nigel1992.github.io/kodi-repository/

Go to Settings → Add-ons → Install from zip file, pick the source and select the repository zip.

Done! The rest of the add-ons are now available under Install from repository.
